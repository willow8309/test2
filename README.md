# 🌷 To-infinitive or Gerund?

## 중학교 1학년 영어 문법 2분 연습 앱

### 📌 앱 소개

**To-infinitive or Gerund?**는 한국 중학교 1학년 EFL 학습자가
**to부정사(to + 동사원형)**와 **동명사(-ing)**의 형태와 쓰임을 짧은 시간
안에 구별하도록 돕는 문법 연습 앱입니다.

복잡한 문법 설명을 먼저 제시하기보다, 학생이 문장을 읽고 직접 답을
선택한 뒤 **오답에 따라 단계적으로 힌트를 받는 방식**으로 구성했습니다.
한 번의 활동은 약 **2분** 정도를 목표로 합니다.

------------------------------------------------------------------------

### 🎯 학습 목표

학생은 문장 속 선행 동사를 단서로 활용하여 다음 두 형태를 구별할 수
있습니다.

-   🌸 **to부정사를 목적어로 취하는 동사**: `want to ~`, `decide to ~`,
    `hope to ~`
-   🌿 **동명사를 목적어로 취하는 동사**: `enjoy -ing`, `finish -ing`,
    `practice -ing`

즉, 단순히 `to`와 `-ing`의 모양을 암기하는 것이 아니라 **앞에 있는
동사가 뒤에 어떤 형태를 요구하는지** 판단하는 것이 핵심입니다.

------------------------------------------------------------------------

### 👩‍🎓 학습 대상

-   한국 **중학교 1학년**
-   to부정사와 동명사를 처음 학습하거나 복습하는 학생
-   EFL(English as a Foreign Language) 학습자
-   수업 전후 **짧은 Review / Warm-up / Exit Ticket** 활동이 필요한 경우

------------------------------------------------------------------------

### ⏱️ 활동 시간

**약 2분**

화면 상단에 `02:00` 타이머가 표시되어 학생이 짧은 시간 동안 집중해서
문제를 해결할 수 있도록 설계했습니다.

------------------------------------------------------------------------

### 🎮 활동 방법

1.  영어 문장을 읽습니다. 👀
2.  두 개의 선택지 중 알맞은 형태를 선택합니다.
3.  정답이면 바로 정답 피드백을 확인합니다. 🌟
4.  오답이면 힌트를 읽고 다시 시도합니다. 💡
5.  한 문제당 **최대 3번**까지 답을 선택할 수 있습니다.
6.  3번째 시도까지 틀리면 정답과 상세한 문법 설명이 제공됩니다. 🌱
7.  모든 문제를 풀면 결과와 핵심 문법을 다시 확인합니다. 🎉

------------------------------------------------------------------------

### 💡 단계적 피드백 구조

#### 1️⃣ 첫 번째 오답

정답을 바로 알려주지 않고, 학생이 **선행 동사의 특성**을 떠올릴 수 있는
첫 번째 힌트를 제공합니다.

#### 2️⃣ 두 번째 오답

좀 더 직접적인 문법 힌트를 제공합니다. 예를 들어
`enjoy + 동명사(-ing)`와 같이 정답을 유추할 수 있는 단서를 제시합니다.

#### 3️⃣ 세 번째 오답

학생이 계속 틀릴 경우 더 이상 추측하게 하지 않고 다음 내용을 제공합니다.

-   ✅ 정답
-   📖 해당 동사가 요구하는 문법 형태
-   🇰🇷 문장의 의미와 용법에 대한 상세 설명

이 구조는 학생이 오답을 내자마자 정답을 보는 대신 **힌트를 이용해 스스로
수정(self-correction)**할 기회를 갖도록 하기 위한 것입니다.

------------------------------------------------------------------------

### 📝 연습 문법

앱에서는 다음과 같은 문장을 연습합니다.

> **I want \_\_\_ a new language.**\
> `to learn` / `learning`

> **She enjoys \_\_\_ music after school.**\
> `to listen to` / `listening to`

> **We decided \_\_\_ home early.**\
> `to go` / `going`

> **My brother finished \_\_\_ his homework.**\
> `to do` / `doing`

> **Jina hopes \_\_\_ a doctor someday.**\
> `to become` / `becoming`

> **They practiced \_\_\_ English together.**\
> `to speak` / `speaking`

학생들이 부담 없이 접근할 수 있도록 강한 원색 대신 **파스텔톤 UI**를
사용했습니다.

-   🩷 Pastel Pink
-   🩵 Sky Blue
-   💚 Mint
-   💜 Lavender
-   💛 Cream / Peach

두 선택지는 서로 다른 파스텔 색으로 구분하고, 진행 상황은 부드러운
그라데이션 progress bar로 보여줍니다. 모바일 화면에서도 사용할 수 있도록
반응형으로 구성되어 있습니다. 📱

------------------------------------------------------------------------

### 🧑‍🏫 수업 활용 아이디어

이 앱은 새로운 문법을 길게 설명하는 본 수업보다는 **짧은 형성평가와 회상
연습**에 적합합니다.

-   🚀 **Warm-up**: 이전 시간에 배운 to부정사와 동명사 복습
-   🔍 **Concept Check**: 문법 설명 직후 이해 여부 확인
-   🧠 **Retrieval Practice**: 선행 동사를 보고 필요한 형태를 빠르게
    회상
-   🎫 **Exit Ticket**: 수업 마지막 2분 개별 확인
-   🏠 **Review**: 결석 학생이나 복습이 필요한 학생의 개별 연습

------------------------------------------------------------------------

### ✨ 핵심 설계 원칙

> **One learning problem → One clear goal → One short learning
> sequence**

이 앱은 여러 문법 요소를 한꺼번에 넣지 않고 **"to부정사와 동명사의
형태를 구별한다"**는 하나의 학습 목표에 집중합니다.

학생은 **문제 해결 → 오답 → 힌트 → 재시도 → 설명 → 복습**이라는 짧고
명확한 학습 흐름을 경험합니다.

------------------------------------------------------------------------
